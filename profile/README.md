## CodeHub(源码门户)
>  [源码门户] ,与计算机连接的门户.
[源码门户] 是一个开源组织,想要制作各种可以使你和计算机连接的应用程序(简单的说就是想做简单易用的工具.)

> 名字的解释:
> 
> Hub -> 门户
> 
> Code -> 源码

## CodeHub 
> [CodeHub] — a gateway connecting you to the computer.
[CodeHub] is an open-source organization dedicated to creating applications that bridge the gap between you and your computer (simply put: building tools that are straightforward and easy to use).

> Name Breakdown:
> 
> Hub -> Portal / Hub
> 
> Code -> Source Code
